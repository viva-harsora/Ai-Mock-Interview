# ToyVerse

A modern, interactive hackathon landing page inspired by the playful and creative world of toys. ToyVerse is designed to provide an engaging visual experience while presenting important hackathon information through a clean, responsive, and user-friendly interface.

Note: This project currently focuses on the frontend experience and visual design. Registration functionality, backend integration, and other dynamic features can be integrated in the future.

## How It Works

1. Open the ToyVerse landing page.
2. Explore the hackathon introduction.
3. View the available themes and tracks.
4. Check the event timeline and prizes.
5. Learn why you should participate.
6. Explore the frequently asked questions.
7. Use the registration call-to-action to participate.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/viva-harsora/ToyVerse.git
```

### 2. Open the Project

Open the project folder in VS Code or your preferred code editor.

### 3. Run the Project

Open `index.html` directly in your browser, or use the Live Server extension in VS Code for the best experience.
